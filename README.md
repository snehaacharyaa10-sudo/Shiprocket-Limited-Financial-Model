# Shiprocket-Limited-Financial-Model
Integrated 3-statement financial model for Shiprocket, covering historical performance and FY27–FY31 forecasts. The model separates Core and Emerging Business revenue, with Q1 FY27 anchors of ₹412 Cr Core (+22% YoY) and ₹180 Cr Emerging (+70% YoY), and forecasts revenue growth, EBITDA, PAT, working capital and cash flows. .
